## 后续子需求输入摘要

- P1-03/P1-05（认证适配）：必须同时透传会话 Cookie 与 `New-Api-User` 头；登录失败走 HTTP 200＋success:false；注册默认开放（上线前需决定开关）；退出真正失效。
- P1-06（Key）：创建不回显明文，需二次取回；列表 key 掩码；启停走 `status_only`。
- P1-08（模型价格）：模型目录需登录；倍率接口默认关闭。
- P1-09/P1-10（日志钱包）：日志列表需管理员；真实充值与邮件改密缺外部条件。
- P1-07（网关）：Relay 认证边界已验证，edge 未开放。
