# 第二阶段统计与流水口径

基线版本：`p2-2026-09-22-a`。

> **下游使用约定**：DTO 对 `null`、未知状态和不可用指标必须显式表达，不得回填零值或估算值。

## 六项 Dashboard 指标口径

| 指标 | 权威来源 | 分子 | 分母 | 结论 | 说明 |
|---|---|---|---|---|---|
| 请求总数 | `/api/log/self` | type=2 或 type=5 日志条数 | 无 | **条件可用** | type=5 错误日志的实际存在性未在样例中出现，需后续验证 |
| Token 用量 | `/api/log/self` | `prompt_tokens + completion_tokens` 求和 | 无 | **已验证** | 样例已观测到真实整数值（31+20=51 tokens） |
| 消费总额 | `/api/log/self` | type=2 日志 `quota` 求和 | `quotaPerUsd`（未冻结） | **条件可用** | quota 到美元的换算比例 `quotaPerUsd` 未取得独立证据 |
| 活跃 Key | `/api/log/self` | 去重 `token_id` 计数 | 无 | **已验证** | 样例含 2 个不同 `token_id`（已脱敏为占位符） |
| 成功率 | `/api/log/self` | type=2 条数 | type=2 + type=5 条数 | **条件可用** | type=5 是否代表失败待裁决 |
| 平均延迟 | `/api/log/self` | `use_time` 求和 | type=2 条数 | **已验证** | 样例 `use_time` 为 1-7 秒真实值 |

## 流水映射

| 流水类型 | 来源接口 | 方向 | 结论 | 说明 |
|---|---|---|---|---|
| 充值 | `/api/user/topup/self` | 入 | **条件可用** | 测试环境未构造真实充值记录，状态枚举与 trade_no 字段类型未验证 |
| 消费 | `/api/log/self` | 出 | **条件可用** | 基于 type=2 日志的 `quota` 字段 |
| 退款 | — | 未知 | **不可用** | 未找到可与消费关联的退款类型/标识/金额字段；**不得按金额正负号推断退款** |

## 时间规则

| 项 | 规则 | 结论 |
|---|---|---|
| 时间单位 | Unix 秒（样例中 `created_time` 为整数秒级） | **已验证** |
| Portal 边界 | `[startTime, endTime)` | **已验证** |
| `/api/log/self` 时间过滤 | `start_timestamp` / `end_timestamp` 参数有效 | **已验证** |
| `/api/log/self/stat` 时间过滤 | 参数不生效，返回当前瞬时值 | **存在差异** |
| `/api/data/self` 小时桶 | 探测窗口内未观察到聚合数据 | **条件可用** |
| 跨 UTC 日界 | 未在本轮专门探测 | **条件可用** |
| 夏令时自然日 | 未在本轮专门探测 | **条件可用** |

## 金额与精度

| 项 | 规则 | 结论 |
|---|---|---|
| 计算类型 | 累计阶段使用 `BigDecimal`，原始 quota 直接累计 | **已验证** |
| `quotaPerUsd` 换算 | 未在本轮取得独立换算证据 | **条件可用** |
| 舍入时机 | 展示阶段统一舍入，计算阶段不提前舍入 | **已验证** |
| 未知单位处理 | 无法确认单位时不参与正式金额计算 | **已验证** |

## 下游 DTO 约定

1. **null 处理**：当指标不可用或字段未验证时，下游 DTO 必须返回 `null`（或对应缺失语义字段），不得回填 `0` 或 `0%`。
2. **未知状态**：充值/消费/退款记录出现未验证状态时，映射结果使用显式未知状态，保留诊断证据，不默认为成功。
3. **不可用指标**：标记为 `不可用` 的指标（如退款）不得出现在正式响应中，或通过独立通道显式声明。
4. **口径版本**：后续 LANG-P2-02 至 LANG-P2-09 的正式契约必须引用 `baselineVersion = p2-2026-09-22-a`；任何口径调整都必须作为显式兼容性变更重新验证。
