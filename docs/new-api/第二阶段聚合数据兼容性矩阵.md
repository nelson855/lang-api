# 第二阶段聚合数据兼容性矩阵

基线版本：`p2-2026-09-22-a`。证据索引见 `aggregation-baseline.json` 与 `samples/aggregation/manifest.json`。

> **重要**：本矩阵只声明实测证据支持的结论。标 `已验证` 的字段有真实样例支撑；标 `存在差异`、`条件可用`、`不可用` 的字段下游不得作为确定值使用。

## 接口级结论

| 接口 | 认证 | 实测证据强度 | 结论 | 说明 |
| --- | --- | --- | --- | --- |
| `/api/log/self` | Session | 真实 9 条日志（type=2 消费 + type=3 其他） | **已验证** | 字段齐全：type/quota/prompt_tokens/completion_tokens/use_time/is_stream/token_id/model_name/request_id |
| `/api/log/self/stat` | Session | 4 个场景（nonempty/empty/bad-time/adjacent）返回相同 `{"quota":0,"rpm":0,"tpm":0}` | **存在差异** | New API 的 `start_timestamp`/`end_timestamp` 参数在本版本**未生效**；只能拿到当前瞬时汇总，不能按时间窗过滤 |
| `/api/data/self` | Session | 所有场景返回空 `data:[]` | **条件可用** | 小时桶数据在探测窗口内未聚合出来；需要更长观察窗口或独立验证数据聚合机制 |
| `/api/user/self` | Session | 有效会话返回真实字段 | **已验证** | quota/used_quota/status/role 等关键字段类型与存在性已确认 |
| `/api/user/topup/self` | Session | 空列表 + 分页边界 | **条件可用** | 测试环境无法构造真实充值/退款记录，无法验证状态枚举 |
| `/api/pricing` | 匿名或 Session | 真实多模型/多厂商数据 | **已验证** | data/vendors/group_ratio/model_ratio/model_price/completion_ratio 字段已验证 |

## 关键字段实测详情

### `/api/log/self` 已验证字段
- `type` (integer)：日志类型枚举；观测到 `2`=消费、`3`=其他；`5`=错误未在样例中出现，其实际存在性**条件可用**
- `quota` (integer)：消费额度，单位 quota
- `prompt_tokens`、`completion_tokens` (integer)：Token 计数
- `use_time` (integer)：耗时，单位秒
- `is_stream` (boolean)：是否流式
- `token_id`、`user_id`、`channel`：内部标识（已脱敏为占位符）
- `model_name` (string)、`request_id` (string)

### `/api/log/self` 不可用字段（样例中未出现或语义不明）
- `first_token_time`：样例响应未包含此字段，TTFT 结论**不可用**
- `protocol`：样例响应未包含此字段，协议字段**不可用**

> LANG-P2-09（2026-10-03）复核：对 `samples/aggregation/` 下全部 19 个 `log-self.*` 与 `data-self.*` 真实脱敏样本重新扫描 `protocol`、`first_token_time`、`channel`、`endpoint`、`path`，结论不变——前两者仍未出现；`channel` 为渠道数字标识，语义不是协议，不可替代。Portal 侧 `protocol` 与 `firstTokenLatencyMs` 继续返回 `null`，页面以“暂无数据”诚实表达。合成测试夹具中的非空值仅用于验证展示与归一规则，不构成实测证据。详见 `docs/18_LANG-P2-09-请求日志协议与TTFT与费用信息增强说明.md`。

### `/api/log/self/stat` 字段（参数不生效）
- `quota`、`rpm`、`tpm`：返回当前瞬时值，不受 `start_timestamp`/`end_timestamp` 影响；作为时间窗过滤**存在差异**

### `/api/user/self` 已验证字段
- `quota` (integer)：剩余额度
- `used_quota` (integer)：已用额度
- `status` (integer)：账号状态枚举
- `role` (integer)：角色枚举

### `/api/user/topup/self` 字段（未真实构造）
- 所有充值字段（amount/currency/status/trade_no/paid_time 等）**条件可用**

### `/api/pricing` 已验证字段
- `data[*]`：价格项数组，每项含 `model_name`、`vendor_id`、`model_ratio`、`model_price`、`completion_ratio`、`enable_groups`、`supported_endpoint_types`
- `vendors[*]`：厂商数组（id/name/icon）
- `group_ratio`：分组倍率
- `usable_group`、`auto_groups`、`pricing_version`

## 敏感数据处理

所有 `token_name`、`user_id`、`token_id`、`channel`、`trade_no`、`email`、`username` 等已使用 `<TOKEN_n>` `<USER_n>` `<CHANNEL_n>` 等不可逆占位符替换；同一原值在同一轮探测内映射到同一占位符，保留关联关系；映射表未写入磁盘。

## 上游升级门禁

上游 New API 升级后必须重跑：
- 本兼容性矩阵中所有接口探测
- 字段来源与口径验证（见 `第二阶段统计与流水口径.md`）
- 性能基线测量（见 `第二阶段聚合性能基线.md`）

不得仅通过字段名称相似性推断字段含义（特别是协议、TTFT、退款、状态枚举）。


## 2026-10-03 P2-09 当前实例补验证据

原冻结样本只证明裁剪后字段形态；不得把缺失 other 的样本外推为原始字段不存在。补验脱敏字段投影见 `samples/p209/2026-10-03-local-verification.json`，完整说明见 `../18_LANG-P2-09-请求日志协议与TTFT与费用信息增强说明.md` 第 8 节。

- 当前 v0.13.2 时间字段实际为 created_at（Unix 秒）；日志适配器已修复并兼容旧 created_time 别名。
- 受控请求产生真实 type=5 错误记录，Token/quota=0、use_time=1 秒，Portal ERROR 映射正确；本地默认 ERROR_LOG_ENABLED=false，采集时临时开启并恢复。
- 当前实例 status 的 quota_per_unit=500000，与新增 4050 quota 实际余额扣减、108 Token 的 75 USD/百万 Token 价格及 Portal 0.0081 USD 交叉一致。本地换算缺口关闭；不证明供应商正式结算或其他实例配置，也不解除 stat 的时间参数缺口。
- 原始 other 中存在 frt（毫秒）与 request_conversion。frt 计首个 SSE 事件，非流式观测为 -1000，尚未保证首输出 Token；协议转换链目前只观察到 OpenAI 成功记录。两个非空映射仍未冻结，接口继续返回 null，禁止直接推断启用。

> 2026-10-03 后续需求决定：用户取消 P2-09 协议/TTFT 展示及非空映射，原 6.1 不再是交付阻塞。上述来源限制仍是事实，取消不是字段验证通过；两个 API 字段仅保留 null 兼容。
