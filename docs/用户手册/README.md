## 适用版本与阅读方法

- 编写日期：2026-10-03；依据当前二阶段代码及本地 New API v0.13.2。
- Lang API 按当前前端中文按钮、表单和路由编写；New API 的主要管理菜单与表单已在本地后台只读核对。本文未替你保存后台配置、创建账号或发起付费调用。
- 示例账号、渠道名和价格只是填写示范，不是已有账号、供应商报价或正式运营建议。真实密码、密钥都由你自己填写。
- 默认本地入口：Lang API `http://localhost:8081`；模型调用地址 `http://api.localhost:8081/v1`；New API 后台 `http://127.0.0.1:13000`。实际端口或域名变更时，以管理员给出的地址和 Lang API「开发文档」显示为准。
- 所有终端运维命令默认在仓库根目录执行；普通用户的调用命令可在自己的终端执行。
- 页面名称加粗表示要找的菜单、按钮或字段；代码块表示可以复制的内容。替换示例占位内容后再执行。

## 当前使用边界

当前适合先预建普通用户、给少量测试额度，完成真实调用后边用边测试。需要先知道以下几项：

1. 默认是预览模式，注册入口可能隐藏；已有账号仍可登录。注册开放条件见管理员手册。
2. 在线充值尚未开放；当前由管理员调整账户额度。密钥「无限额度」不会给账户增加余额。
3. 公开网关目前只开放 OpenAI 兼容的模型列表和聊天完成接口；New API 自身具备的其他接口不会因此自动开放给 Lang API 用户。
4. 控制台和钱包的聚合查询最多 7 天，30 天暂不可用；请求日志单独支持最多 30 天。部分统计、充值/退款流水、模型增强资料仍有来源限制。
5. 当前默认 Compose 已记录登录来源配置问题，可能造成网页登录 403。管理员手册提供本地临时配置步骤，业务代码修复仍见[暂缓问题与后续需求清单](../未解决问题/LANG-P2-10_暂缓问题与后续需求清单.md)。

「暂无数据」「部分覆盖」「暂不可用」各有不同含义，不能一律看成 0 或操作失败。具体解释放在对应页面的操作章节。
