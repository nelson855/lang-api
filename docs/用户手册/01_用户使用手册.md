# Lang API 用户使用手册

按第一次使用的顺序：注册或领取账号 → 登录 → 确认余额 → 选模型 → 创建密钥 → 调用 → 查日志与消费 → 管理密钥和个人资料。

Lang API 当前是模型 API 平台：你在网页上管理账号、模型、密钥和记录，在终端、自己的程序或支持 OpenAI 兼容接口的客户端里使用模型。当前 Lang API 没有网页聊天输入框。

## 1. 打开网站与注册

### 1.1 打开网站

1. 打开浏览器，在地址栏输入管理员提供的 Lang API 网站地址。本地默认是 `http://localhost:8081`。
2. 页面右上角可切换 **中文 / English**；本文使用中文界面。
3. 你可以先点 **模型广场**、**开发文档** 或 **服务地区** 浏览公开内容，不需要先登录。
4. 页脚有 **用户协议**、**隐私政策** 和 **联系支持**。先了解服务范围；开发环境的支持地址可能只是占位地址，应向实际管理员确认联系方式。

手机窄屏下先点 **菜单** 找页面；账号入口也可直接用下文地址打开。

### 1.2 注册开放时

1. 点击页面右上角或页脚 **注册**，进入 `/register`；本地完整地址为 `http://localhost:8081/register`。
2. 点击 **用户协议**、**隐私政策** 阅读正文，阅读后用浏览器返回注册页。
3. 按下表填写。

| 字段 | 填写内容 | 示例与要求 |
|---|---|---|
| 用户名 | 自己选择的登录名 | 例如 `manualuser01`；至少 3 个字符。首次测试用 3～12 位英文字母/数字可避免上游长度差异 |
| 密码 | 自己生成并保存的密码 | 至少 8 个字符；不要使用本文账号名作为密码 |
| 确认密码 | 再输入同一密码 | 必须与上面的密码完全相同 |

4. 想检查密码是否输错，可以点密码框旁 **显示输入内容**；检查后点 **遮蔽输入内容**。
5. 点击 **注册**，提交期间显示 **提交中…**，等待完成。
6. 注册成功会跳转到 **登录** 页。此时尚未登录，需要按第 2 节输入刚注册的账号。

当前注册表单只有三个输入框和法律正文链接，没有邮箱、验证码或独立的协议勾选框。不要寻找不存在的控件。用户名/密码长度不够时提交不会继续；两次密码不同会显示 **两次输入的密码不一致。**

### 1.3 看不到注册，或显示注册关闭

直接打开 `/register` 可确认状态：

| 页面提示 | 你要做什么 |
|---|---|
| 当前为预览版本，暂未开放注册 | 请管理员在 New API 预建普通账号，然后直接登录 |
| 当前环境未开放注册，请联系管理员预建账号 | 领取预建账号，无须自己在 New API 注册 |
| 法律正文尚未就绪，暂未开放注册 | 等管理员补齐正文和配置，或领取预建账号 |
| 注册提交后显示请求失败 | 检查输入；再请管理员核对上游注册策略、账号重名和服务状态 |

只打开 New API 的注册开关，不保证 Lang API 注册开放。当前本地默认预览模式下，使用预建账号是最直接的试用路径。

## 2. 登录并认识控制台

1. 首页点击 **登录**，或直接打开 `http://localhost:8081/login`。
2. **用户名** 填自己注册或管理员提供的登录名。
3. **密码** 填对应密码。
4. 点击 **登录**。成功后通常进入 **控制台**；若此前访问过受保护页面，可能返回那个页面。

登录后左侧菜单如下；手机先点顶部 **菜单**。

| 菜单 | 用途 | 路径 |
|---|---|---|
| 控制台 | 余额、统计和最近请求 | `/dashboard` |
| API 密钥 | 新建、复制、限制、停用和删除密钥 | `/dashboard/api-keys` |
| 请求日志 | 查每次调用及费用 | `/dashboard/request-logs` |
| 钱包 | 当前余额、区间消费和账户活动 | `/dashboard/wallet` |
| 个人设置 | 修改资料和密码 | `/dashboard/settings` |

点击左上角 **Lang API** 标志可以回首页，再进入公开的模型广场和开发文档。直接打开控制台路径也可以回到登录后的区域。

**用户名或密码错误。**：重新核对登录名和密码；连续失败先暂停，当前同一用户名的登录限制为 5 分钟 5 次。若显示 **请求失败，请稍后重试。**，尤其是本地第一次使用，请管理员先查管理员手册中的登录 403 问题，不要不停改密码重试。

## 3. 先确认账户余额

1. 左侧点击 **钱包**。
2. 看顶部 **余额**：页面同时显示货币金额和 `quota`。
3. 若余额为 0 或不足，请管理员为你的普通用户分配测试额度；当前网页没有在线支付充值按钮。
4. 管理员完成后重新加载钱包，确认余额已变化，再继续创建密钥和调用。

`quota` 是系统扣费使用的内部额度单位，不是模型处理的文本 Token。当前本地已验证 `500000 quota = 1 USD`，其他环境必须以管理员确认的换算为准。USD 表示美元计价单位，不表示你已经进行了美元支付。

账户余额是所有密钥共享的总余额；密钥的有限额度只是这一枚密钥可以消耗的上限。创建密钥不会自动充值。

## 4. 选择模型

### 4.1 在模型广场找到模型

1. 回到首页，点击 **模型广场**；也可直接打开 `/models`。
2. 在 **搜索模型** 输入模型 ID 的片段；例如你知道要找 `deepseek` 就输入它。结果随输入更新，没有单独的查询按钮。
3. 需要缩小范围时，在 **厂商筛选** 选择一个厂商；恢复全部时选择 **全部厂商**，或点 **清除厂商条件**。
4. 看模型卡片上的完整模型 ID、厂商和基础价格。
5. 点击 **复制模型 ID**，保存完整 ID，后面填写 `model` 就用它，不用中文显示名或自行缩写。

模型 ID 是调用时精确指定模型的字符串。厂商筛选只是筛选目录，并不是为你的账户购买某个厂商权限。

### 4.2 看模型详情

1. 在对应模型卡片点击 **查看详情**。
2. 按顺序看 **模型标识**、**基础价格**、**限制与模态**、**能力**、**发布信息** 和 **增强计费**。
3. **输入 / 输出** 价格一般按「百万 Token」展示；按次模型显示 **每次请求**。Token 是模型处理文本等内容的计量单位，输入和输出分别计量。
4. 看完点 **返回模型广场**，可继续比较；确定使用时点 **查看调用示例**，会进入选中该模型的开发文档。

注意这些显示的含义：

- **暂无数据**：当前来源没有可信资料，不代表上下文无限，也不代表功能不支持。
- **价格暂不可用**：当前无法展示价格，不能解释成免费。
- **增强价格暂无数据**：缓存、图像等额外收费未取得完整依据，不能解释成没有额外收费。
- **目录可用性**：模型出现在目录，不承诺你的密钥和账户能调用；还取决于渠道、分组、余额和密钥限制。
- **基础价格**：目录参考价；实际扣费还可能受分组倍率影响，以实际日志、余额变化及管理员说明核对。

当前公开网关只支持聊天完成接口。详情中即使有其他能力信息，也不表示对应公开接口已经开放。不要手工拼接模型详情链接；使用 **查看详情** 按钮即可。

## 5. 创建和复制 API 密钥

API 密钥是程序调用模型时使用的凭证，相当于给调用程序的一把钥匙；不是网页登录密码，也不是供应商给管理员的上游密钥。

### 5.1 创建第一枚密钥

1. 打开控制台，左侧点击 **API 密钥**。
2. 点击 **新建密钥**，出现表单。
3. 第一次测试可按下表填写。先确认账户本身有额度。

| 字段 | 第一次测试怎么填 | 说明 |
|---|---|---|
| 名称 | `manual-first-call` | 自己识别用途的名称，1～50 个字符；后面日志按这个名称查 |
| 额度 | 选择 **有限额度** | 限制这枚密钥的可消费额度 |
| 剩余额度 | `50000` | 非负整数，单位是 quota；本地换算约 0.10 USD，只是示例预算，不保证适合所有模型 |
| 过期时间 | 在日期时间控件选未来时间，或留空 | 留空表示永不过期；测试建议设置短期有效时间 |
| 高级限制 → 模型限制 | 填第 4 节复制的完整模型 ID | 一行一个 ID；只允许这些模型。留空不增加模型限制 |
| 高级限制 → IP 限制 | 首次测试留空 | 尚不确认自己的出口 IP 时先不填，避免把自己拦住 |

4. 如果 50000 quota 不足以完成所选模型的一次请求，向管理员确认预算再调整，不要盲目反复调用。
5. 点击弹窗底部 **新建**。
6. 成功后出现 **创建成功** 提示，并回到第一页；新密钥显示在列表中。点 **知道了** 可关闭提示。

**无限额度** 表示不设这一枚密钥的额度上限，仍受账户总余额约束。它不是免费额度，首次测试通常用有限额度更方便控制消费。

### 5.2 显示并复制完整密钥

1. 找到 `manual-first-call` 那一行，点击 **显示并复制**。
2. 阅读风险提示后，点击 **显示明文**。
3. 密钥出现在只读输入框中；点击 **复制**。
4. 出现 **已复制并清除明文。**，把密钥粘贴到自己的密码管理工具或本机受保护配置。
5. 关闭弹窗。

明文显示最长约 60 秒；复制成功、关闭弹窗后会清除页面中的明文。后续可以再次通过 **显示并复制** 获取，不必为复制超时重新创建。列表里的遮蔽值不是完整密钥，不能拿去调用。

如果浏览器复制失败，在密钥输入框内手动全选并复制。不要在聊天、截图、公开仓库或浏览器前端代码中放完整密钥。复制后的系统剪贴板由你管理，网页清除明文不等于清空系统剪贴板。

### 5.3 以后如何填写高级限制

- **模型限制**：展开 **高级限制**，一行一个完整模型 ID；使用目录复制的原文。留空表示不增加模型白名单限制。
- **IP 限制**：一行一个调用机器的公网出口 IPv4 或 IPv6 地址。当前表单不接受网段、域名和端口。
- 这里的 IP 是服务端实际识别的调用来源。家用网络、代理或 VPN 的出口可能变化，变化后需重新确认。
- 当前 Lang API 密钥表单没有分组选择、负载均衡或供应商密钥输入框，普通用户无须配置它们。

## 6. 完成第一次模型调用

### 6.1 准备三项内容

1. 在 **模型广场** 找到模型，点击 **查看调用示例**。
2. 在 **开发文档 → 调用地址** 复制 Base URL。本地默认 `http://api.localhost:8081/v1`。
3. 准备完整 API 密钥和模型 ID。

Base URL 是调用接口的共同地址前缀。这里的地址以 `/v1` 结束，和访问网页的 `http://localhost:8081` 不同。HTTP 请求还需加具体接口路径。

### 6.2 用 Mac 终端发送一条非流式请求

非流式表示等回答完成后一次返回。无需先安装 SDK，Mac 自带的 `curl` 即可测试。

1. 打开 Mac 的 **终端**。
2. 运行以下命令，看到提示后粘贴自己的完整密钥并按回车；输入不会显示在终端里。

```bash
printf '粘贴 Lang API 密钥后按回车：'
read -r -s LANG_API_KEY
printf '\n'
export LANG_API_KEY
```

3. 设置地址和模型。下文 `替换为模型广场复制的完整模型ID` 必须替换成真实 ID；地址以开发文档显示为准。

```bash
export LANG_API_BASE_URL='http://api.localhost:8081/v1'
export LANG_API_MODEL='替换为模型广场复制的完整模型ID'
```

4. 先查你的密钥实际可见的模型。

```bash
curl -sS -i "$LANG_API_BASE_URL/models" \
  -H "Authorization: Bearer $LANG_API_KEY"
```

成功通常返回 HTTP 200 和模型列表；检查目标 ID 是否存在。公开目录和真实密钥可见模型可能不同，列表查询也不能替代实际聊天调用验证。

5. 再发一条短聊天请求。

```bash
curl -sS -i "$LANG_API_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $LANG_API_KEY" \
  -H 'Content-Type: application/json' \
  -d "{\"model\":\"$LANG_API_MODEL\",\"stream\":false,\"max_tokens\":32,\"messages\":[{\"role\":\"user\",\"content\":\"请只回复：测试成功\"}]}"
```

这条示例适用于普通文本聊天、支持 `max_tokens` 的模型。若供应商明确不支持此参数，删除 `"max_tokens":32,` 后再按其规则测试；不要用它测试图片、音频或其他未开放接口。模型 ID 含引号等特殊字符时，直接使用开发文档针对该模型生成的示例，避免手工拼 JSON。

6. HTTP 200 且 JSON 中 `choices[0].message.content` 有回答，说明这一条调用成功。不要求模型逐字回答「测试成功」。若返回错误，记录 HTTP 状态和错误消息后看第 13 节。
7. 进入 **请求日志**，按密钥名称 `manual-first-call` 查到此次记录；再回钱包确认余额和消费。聊天请求会实际消耗额度。

### 6.3 使用页面自带调用示例

1. **开发文档 → 非流式示例 → cURL** 点击 **复制**。
2. 当前页面示例通过 `$LANG_API_KEY` 读取密钥，所以先按 6.2 节设置环境变量，再粘贴示例运行。
3. 页面示例已填入所选模型和当前 Base URL；若直接打开 `/docs`，可能使用目录中的默认模型，建议从模型卡片进入。
4. 也可以复制 **OpenAI SDK** 示例放到自己的服务端项目；SDK 是帮程序组织接口请求的工具库，运行前需要项目已有对应的 `openai` 依赖和执行环境。不要把服务端密钥放进网页脚本。

### 6.4 流式调用

流式表示回答生成时分段返回，页面 **流式示例 → cURL** 会带 `-N` 和 `stream:true`。

1. 保持 `$LANG_API_KEY` 已设置。
2. 复制页面流式 cURL 示例并运行。
3. 正常会连续看到 `data:` 数据行，结束时通常有 `[DONE]`。
4. 若按 `Ctrl+C` 中断，已经处理的内容仍可能计费；结束后查看日志核对。

### 6.5 填到其他客户端

仅使用支持 **OpenAI 兼容 Chat Completions**、允许自定义地址的客户端。

| 客户端字段 | 填什么 |
|---|---|
| 提供商 / 接口类型 | OpenAI 兼容，或支持自定义 Base URL 的 OpenAI |
| API Key | Lang API 完整密钥 |
| Base URL / API 地址 | 开发文档提供的地址，例如 `http://api.localhost:8081/v1` |
| Model / 模型 | 复制的完整模型 ID |

若客户端要的是「完整聊天接口 URL」，填 `http://api.localhost:8081/v1/chat/completions`；若它自动补 `/v1`，按客户端说明填根地址，避免最终请求出现 `/v1/v1`。要求 Responses、Embeddings、图片、音频、Claude 或 Gemini 原生协议的模式，当前不能直接使用。

其他电脑、手机或容器中的 `localhost` 指向它自己，不能使用你 Mac 的本地地址；请管理员提供它可访问的正式模型地址。当前本地入口不能直接当作多人远程服务地址。

测试结束，在终端执行：

```bash
unset LANG_API_KEY LANG_API_BASE_URL LANG_API_MODEL
```

这只清理当前终端变量，不会停用平台上的密钥。要停止该密钥继续被调用，按第 10 节停用或删除。

## 7. 查看请求日志

1. 左侧点击 **请求日志**。
2. **Key 名称** 填 `manual-first-call`；这里是密钥名称，不是 `sk-...` 明文，按完整名称精确匹配。
3. **模型** 填实际调用的模型 ID，或留空查看所有模型。
4. **结果** 选择 **成功** 或 **失败**。当前没有「全部结果」选项，成功和失败要分开查。
5. **时间范围** 选择 **最近 24 小时**、**最近 7 天** 或 **最近 30 天**。
6. 点击 **查询** 才应用输入的条件；只改输入框不会立即查询。
7. 需要重新读取当前已提交条件时点 **刷新**；按钮不是重新提交未保存的筛选。
8. 记录较多时点 **下一页 / 上一页**，每页 20 条。想清除条件就清空 Key/模型输入，选择所需结果，再点 **查询**。

日志各列怎么读：

| 列 | 含义 |
|---|---|
| 时间 | 本次请求的记录时间 |
| Key | 调用所用的密钥名称，缺失时显示暂无数据 |
| 模型 | 调用的模型 ID |
| 流式状态 | 流式或非流式 |
| Token（输入/输出） | 前者输入量，后者输出量 |
| 耗时 | 总耗时，单位 ms；1000 ms = 1 秒 |
| 结果 | 成功或失败的记录结果，可能显示 `SUCCESS` / `ERROR` |
| 费用 | 根据日志 quota 换算的金额，下方同时显示 quota |
| 请求标识 | 用于辅助定位请求；缺失时不能强行一一关联 |

点击 **费用说明** 可展开解释。逐条金额相加可能存在舍入差异；列表不是正式账单。当前页面没有协议、首 Token 延迟、日志详情弹窗或导出按钮。

从控制台 **查看日志** 进入时，会显示 **Dashboard 所选范围**，保留此前时间范围；若要另选 24 小时/7 天/30 天，直接从左侧菜单重新打开不带查询参数的日志页。

**当前筛选没有请求记录。** 表示在这个筛选下没有返回记录。失败请求可能未被上游记录，网关提前拒绝的请求也可能根本没到 New API；「查不到失败」不能当作从未发生失败。请管理员查后台和服务日志。

## 8. 查看控制台统计

1. 左侧点击 **控制台**。
2. **当前余额** 是现在可用的额度；点 **查看钱包** 进入钱包。
3. 在 **时间范围** 选择 **最近 1 小时 / 最近 24 小时 / 今天 / 昨天 / 最近 7 天**，统计随选择更新。
4. 看 **请求总数、Token 用量、消费总额、活跃 Key、成功率、平均延迟**；活跃 Key 表示所选范围中有活动的密钥。
5. 看 **请求趋势**、**消费趋势** 和 **最近请求**；点 **查看日志** 查看该范围的记录。

时间按页面显示的时区解释；「今天」是该时区的当天，「最近 24 小时」是向前滚动 24 小时，两者不相同。**最近 30 天** 当前被禁用，不要通过手改 URL 绕过。

当前来源限制会让部分指标或趋势显示 **基线尚未验证，暂不可用。**、**来源字段缺失，暂不可用。** 或 **部分来源覆盖**。这些不是 0；仅看到某些请求记录，不能据此认定成功率和请求总数已完整覆盖。聚合结果默认缓存约 30 秒，调用后短时间内未更新可等待后再读取。

若统计加载失败而余额正常，只在失败区域点 **重试**。选 7 天时报错，可先选 1 小时或 24 小时；当前聚合有读取量和超时保护，范围过大不一定能返回完整结果。

## 9. 查看钱包和统一流水

1. 左侧点击 **钱包**，先看 **余额**。这是当前余额，不随历史时间筛选变化。
2. **范围内消费 → 时间范围** 选择 **24 小时 / 今天 / 昨天 / 近 7 天**。
3. 查看 **消费条数、消费额度、正式货币金额**。当前正式聚合金额可能显示 **正式货币换算尚未验证，金额暂不可用。**，仍可核对已返回的消费 quota。
4. 向下看 **统一流水**，在 **交易类型** 选择 **全部 / 充值 / 消费 / 退款**。
5. 看 **时间、类型、方向、金额、状态、备注、来源**；消费一般是支出，充值一般是收入。
6. 需要时点 **下一页 / 上一页**。换范围会同时影响消费汇总和统一流水；换交易类型只筛选流水，不修改消费汇总。
7. 再看 **充值记录**，它来自单独的兼容来源，有自己的分页，不跟随上面的时间范围和类型筛选。

当前 **近 30 天** 暂不可用；**充值未开放** 是真实状态，没有充值金额框、支付宝按钮或二维码。额度不足时联系管理员。

统一流水是只读账户活动，不是银行账单或正式发票。充值/退款可能显示来源不可用；管理员手动增加额度也不一定生成这两类流水。不能把所有流水相加推算账户余额，不能把「退款来源不可用」看成确认没有退款。

某个区块 **加载失败** 时点该区块的 **重试**；其他区块已加载的内容可以继续查看。

## 10. 日常管理密钥

### 10.1 找到目标密钥

1. 点击 **API 密钥**。
2. **搜索密钥** 输入名称，稍等搜索结果更新；当前没有独立查询按钮。
3. **状态筛选** 可选 **全部状态 / 启用 / 停用 / 已过期 / 额度用尽**。
4. 多页时用 **上一页 / 下一页**。没有结果时清除名称、恢复全部状态。

### 10.2 编辑限制

1. 在目标行点击 **编辑**。
2. 修改 **名称、额度模式、剩余额度、过期时间、模型限制、IP 限制** 中需要调整的项。
3. 点 **保存**；取消则点 **取消**。
4. 核对列表和实际调用；增加密钥额度不会增加账户余额。编辑剩余额度表示设置这枚密钥的新剩余额度，不是给账户充值。

过期的密钥需把过期时间改为未来或留空；额度用尽的有限密钥需补足其剩余额度，并同时检查账户余额。当前过期/用尽行没有普通的启用/停用按钮。

### 10.3 停用与重新启用

1. 暂时不用或怀疑泄漏时，在目标行点击 **停用**。
2. 弹窗核对名称和提示，点击 **确认停用**；列表应显示停用。
3. 再用该密钥调用应被拒绝。
4. 要恢复时点 **启用 → 确认启用**。余额、有效期和限制仍需满足，启用不会充值或延长有效期。

### 10.4 删除与轮换

1. 不再需要时点击 **删除 → 确认删除**。删除不可恢复，已有程序中的该密钥将不能继续使用。
2. 正常轮换时先新建一枚密钥，复制并替换程序配置，完成一条真实调用后再停用旧密钥，最后删除。
3. 若旧密钥已经泄漏，先停用它阻止继续消费，再创建和替换新密钥。

若显示 **结果未知**，先刷新页面核对是否已新建/修改/停用，不要立即重复点击提交，以免重复创建。保留提示中的请求标识交给管理员。

## 11. 修改个人资料与密码

### 11.1 只改资料

1. 左侧点击 **个人设置**。
2. **用户名** 填要使用的登录名；保留原值则不修改。至少 3 个字符，使用未占用的名称。
3. **显示名** 填希望页面显示的名字，例如 `测试用户`；可留空。
4. **邮箱** 当前只读，不能在这里绑定或修改。
5. 在 **修改密码** 区域的 **当前密码** 填现在的登录密码；即使只改显示名，也必须填。
6. **新密码、确认新密码** 都留空。
7. 点击 **保存修改**，看到 **资料已更新。**，检查新资料。修改用户名后，下次登录用新用户名。

### 11.2 修改密码

1. 在同一页保留或修改基础资料。
2. **当前密码** 填现在的密码。
3. **新密码** 填自己生成的至少 8 位新密码。
4. **确认新密码** 再填同一个新密码。
5. 点击 **保存修改**，出现 **资料已更新。** 后保存新密码。
6. 退出，再用当前用户名和新密码登录，确认修改成功。

**当前密码不正确。** 就重新核对当前密码；**用户名已被占用。** 就换一个用户名。出现 **更新结果未确认** 时先点 **重新读取资料** 核对；密码是否已改变需通过登录验证，不要盲目连续提交。

忘记密码时联系管理员，当前 Lang API 没有自助找回密码、邮箱验证码或第三方登录入口。改登录密码和退出网页都不能替代停用已泄漏的 API 密钥。

## 12. 其他公开入口与退出

- **首页**：入口和调用示例展示，不是聊天界面。
- **开发文档**：鉴权、Base URL、已开放接口和所选模型的非流式/流式示例。
- **服务地区**：查看当前公布的服务地区；未公布时联系管理员，不能自行推定全球可用。
- **用户协议 / 隐私政策**：页脚进入；法律正文未发布时显示未发布提示，联系管理员。
- **联系支持**：页脚点击已配置的支持链接；未公布或开发占位地址时向实际管理员确认。
- **语言**：在可见的语言选项中选中文或 English；名称变化时本手册对应中文名称。
- **退出登录**：桌面控制台左侧底部点击，提交后返回首页。当前手机侧栏不显示该按钮时，可在浏览器使用桌面版网站再操作。退出只结束此次网页会话，API 密钥继续有效。

## 13. 遇到问题时怎么办

| 情况 | 先做的操作 | 需要管理员协助时提供什么 |
|---|---|---|
| 登录显示用户名或密码错误 | 核对登录名和密码，暂停连续重试 | 用户名、发生时间；不提供密码 |
| 登录显示请求失败，尤其本地首次使用 | 联系管理员核对允许来源配置 | 网页地址、时间、是否 HTTP 403 |
| 调用 401 | 确认使用完整 API 密钥，检查停用/过期 | 密钥名称、状态、错误消息；不提供明文 |
| 调用 403 | 查模型/IP 限制和所用地址 | 模型 ID、调用出口 IP、接口路径 |
| 提示余额或令牌额度不足 | 先看钱包，再查这枚密钥额度 | 用户名、密钥名称、余额情况 |
| 模型不可用或无可用渠道 | 核对完整模型 ID，向管理员确认开放范围 | 模型 ID、密钥名称、调用时间 |
| 调用 404 或接口未开放 | 使用开发文档地址，检查有无重复 /v1 | 实际 URL，不附认证头 |
| 调用 429 | 减少并发和频率，等待再试 | 调用频率、时间、错误消息 |
| 调用 400 | 核对 JSON、model 和参数，先用短文本示例 | 不含密钥、私人提示词的参数摘要 |
| 调用 502/503/504 | 保存错误，稍后重试；避免无限循环 | 时间、模型 ID、HTTP 状态、请求标识（有则提供） |
| 页面加载失败 | 点该区块重试；若跳登录页则重新登录 | 页面地址、时间、提示中的请求编号 |
| 调用成功但日志暂时看不到 | 核对结果=成功、Key 名称、时间范围，点查询/刷新 | 密钥名称、模型、时间、返回状态 |
| 统计与日志不完全一致 | 核对同一范围、时区和覆盖提示，等待缓存更新 | 选中范围、时区、差异项 |

状态码只是排查入口，不足以单独断定原因；以响应里的具体错误消息为准。报告问题时保留请求标识（若存在），绝不要发送完整 API 密钥、密码、Cookie 或未脱敏的请求截图。
