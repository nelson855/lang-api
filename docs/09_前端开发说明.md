# 前端开发说明（LANG-P1-04 交付）

本文档记录独立前端骨架的目录职责、设计变量、组件用法、路由、国际化、数据访问、测试命令，以及后续需求（尤其是 LANG-P1-05）接入时的约束。

## 目录职责

```text
frontend/src/
├── app/
│   ├── providers/       # Query、public-config 门禁（React 上下文与数据缓存）
│   ├── router/          # 路由元数据、懒加载路由表、路由错误页
│   └── App.tsx          # Provider 装配顺序：i18n → Query → PublicConfigGate → AuthState → Toast → Router
├── api/                 # 无 React 依赖：路径白名单、响应校验、统一请求客户端、公开配置查询
├── components/
│   ├── ui/              # Button/Input/FormField/Dialog/DataTable/Pagination（只管表现）
│   ├── feedback/        # Loading/Empty/Error/Forbidden/NotFound/Toast（通用页面状态）
│   └── brand/           # 可替换临时标识（几何标记 + 运行时站名）
├── design/              # tokens.css（三层变量）、global.css（排版/焦点/容器/动效）
├── features/auth/       # 鉴权状态、守卫、返回地址校验（P1-05 替换数据源，不改守卫 API）
├── i18n/                # 语言识别、资源、Provider、切换器、格式化
├── layouts/             # Public/Auth/Console 三类布局与页面标题/焦点钩子
├── pages/               # 本阶段页面（每个独立模块，供路由懒加载）
└── test/                # render helper、axe 类型、应用级渲染 helper
```

页面组合布局、查询与功能；接口层不知道 React；Provider 负责应用级生命周期。

## Clear Circuit 设计变量

- 项目采用 Clear Circuit 浅色视觉：冷调灰白画布、白色工作面、石墨文字与钴蓝主操作。项目根级 `DESIGN.md` 记录视觉基线，`UX-CONTRACT.md` 记录不得因换肤改变的交互后果。
- `src/design/tokens.css` 是运行时唯一真实来源。全部十六进制颜色只允许出现在该文件，映射顺序为 `DESIGN.md` → `tokens.css` primitive/semantic/component → Tailwind `@theme` → 共享组件。
- 圆角三档 6/10/16px；正文与控件对比度满足 WCAG AA（`tokens.test.ts` 自动核验）。
- 内容容器 `.app-container` 最大约 1180px，窄屏内边距 16px，导航断点 768px；数据表用 `.table-scroll` 自身横向滚动。
- 搜索、筛选等工具栏控件使用 36px 紧凑密度；登录、注册和普通表单使用 40px 标准密度。认证表单最大宽度约 420px，避免字段在宽屏中过度拉伸。
- `prefers-reduced-motion` 下关闭装饰过渡，保留状态反馈。
- 字体为本地打包的 Manrope Variable（正文）与 JetBrains Mono Variable（代码/地址/编号），不请求外部字体。

## 组件 API

- `Button`：`variant`（primary/secondary/quiet/danger）、`size`（sm/md）、`loading`（保持可访问名称并禁用）、`disabled`。
- `Input` + `FormField`：`label`/`description`/`error`/`required` 自动关联 `id`/`aria`；`density="standard"` 为 40px，`density="compact"` 为 36px；与 React Hook Form/Zod 直接组合（见 `FormField.test.tsx` 的 fixture）。
- `Dialog`：基于 Radix，`open`/`onOpenChange`/`title`/`description`/`actions`；自带焦点恢复；移动抽屉用 `contentClassName="dialog-drawer"`。
- `DataTable`：`columns`/`rows`/`emptyText`，只做语义表格与空状态。
- `Pagination`：`page`/`pageSize`/`total`/`onChange`，只回调合法页码。
- `ToastProvider` + `useToast()`：`success/info/warning/error`，自动关闭，可手动关闭，`aria-live`；错误可带 `requestId`，不渲染原始异常。
- 页面状态：`Loading`/`Empty`/`RetryableError`（带 requestId 与重试）/`Forbidden`/`NotFound`。

选择器继续由原生 `<select>` 拥有弹层、键盘与平台兼容性，项目仅统一触发器视觉；`datetime-local` 同理由浏览器拥有日期时间弹层，不替换既有 ISO 转换语义。

## 路由元数据

- `src/app/router/routeMeta.ts` 的 `ROUTE_META` 是唯一路由声明：每条有稳定 id、路径、布局、访问级别、标题键；公开导航由带 `navKey` 的条目派生。
- 页面模块懒加载，布局与启动门禁保留在初始包；未知路径走前端 `*` 自有 404；`/portal/api/*` 与 `/actuator/*` 仍是服务端边界。
- 路由切换后布局负责更新文档标题（运行时站名 + 当前语言标题）并把焦点移到主标题。

## 国际化

- `zh-CN` 与 `en-US` 资源按 `common`、`nav`、`pages`、`states`、`errors` 分域，键为语义标识；`resources.test.ts` 递归保证键集合与插值参数一致。
- 初始语言优先级：已保存选择 → 浏览器首个支持语言（`zh*`/`en*` 映射）→ `zh-CN`；切换后持久化并同步 `<html lang>` 与文档标题，不改变路由状态。
- 日期/数字/金额走 `src/i18n/format.ts` 的 `Intl` 集中入口；缺币种或额度单位时返回空状态，不猜测金额。
- 译文一律按文本节点渲染，禁止传入 `dangerouslySetInnerHTML`。

## 数据访问

- 所有业务请求走 `portalRequest(path, schema, { signal, body })`：只接受站内 `/portal/api/*` 相对路径，查询参数用结构化值构造；同源凭证、`Accept: application/json`、合法 `X-Request-Id`；调用方取消信号原样透传。
- 成功包 `{requestId, data}` 与失败包 `{requestId, error}` 经 Zod 运行时校验；非法响应只报通用协议错误，不渲染原始正文；取消是独立错误类型，界面静默处理。
- `QueryClient` 全局保守：查询不重试、窗口聚焦不刷新、mutation 不重放；`public-config` 用固定 key、永不过期、失败只等手动重试。
- 页面/组件/布局禁止直接调用 `fetch`、声明绝对地址或引用原始 `/api/*`：ESLint 规则 + `apiBoundaries` 单元测试 + 真实源码守卫测试三层拦截（安全校验代码自身需持 `api-boundary-exempt:` 标记并写明理由）。

## 测试命令

- `npm run lint`：类型 + 规则（含 API 边界规则）。
- `npm run test`：Vitest 单元/组件/集成测试（含 axe 自动检查）。
- `npm run build`：生产构建（无 sourcemap，资源本地化）。
- `npm run test:e2e`：Playwright 浏览器流程（需先安装锁定 Chromium，见 `playwright.config.ts`；不进入默认 Maven `verify`）。

## P1-05 接入约束

- 把 `DefaultAuthProvider` 的 `anonymous` 替换为真实当前用户查询的数据来源；`AuthState` 的四状态与 `RequireAuth`/`PublicOnlyRoute` 的 API 不变。
- 登录/注册页的真实表单与 schema 由 P1-05 新增，沿用 `FormField` + `Input` + Zod 组合模式。
- 控制台导航在对应功能落地时逐项增加，不提前展示不可用菜单。
