## 7.5 开发类似产品时最容易遗漏的功能

> 以下为**产品开发建议**，不是对 QinghuaAPI 现有功能的断言。

1. **API Key 生命周期**
   - 创建后完整 Key 仅展示一次
   - Key 前后缀脱敏
   - 停用而非直接删除
   - 独立限额、模型白名单、IP 白名单
   - 最后使用时间

2. **费用保护**
   - 账户余额预警
   - Key 级每日/月消费上限
   - 单请求最大 Token / 最大费用
   - 防止重试风暴导致重复扣费

3. **模型治理**
   - 模型可用状态
   - Provider 故障
   - Deprecated / Sunset
   - 上下文与模态能力版本化
   - 价格变更记录

4. **请求日志可追溯性**
   - Request ID
   - 用户 Key
   - 模型
   - 实际 Provider
   - Token
   - Cache Token
   - Cost
   - Latency
   - HTTP Status
   - 错误类型
   - 重试/路由次数

5. **异步多媒体任务**
   - 图片/视频生成任务状态
   - Polling / Webhook
   - 失败退款或扣费规则
   - 结果文件生命周期

6. **支付安全**
   - 订单幂等
   - Webhook 验签
   - 支付成功与到账分离
   - 重复回调
   - 退款/Chargeback
   - 交易流水不可变更审计

7. **协议与地区合规**
   - 协议版本号
   - 用户同意时间
   - 同意的具体版本
   - 协议更新后的重新同意机制
   - 国家/地区限制与服务可用性

8. **安全设置**
   - MFA
   - Session 管理
   - 登录历史
   - 风险登录
   - API Key 泄露检测

9. **开发者体验**
   - Copy model ID
   - Copy curl
   - Copy SDK code
   - 错误码说明
   - Rate Limit Header
   - Playground 与真实计费边界提示

### 实际可见特征

   - `/docs/...` 存在统一的 `Docs Not Found` 页面。
   - 表明文档系统有独立的 slug/path 路由与缺省错误页。

   - 控制台有 API Keys / Usage Monitoring 等动态数据能力。
