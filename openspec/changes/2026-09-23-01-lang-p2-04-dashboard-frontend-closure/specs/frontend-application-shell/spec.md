## MODIFIED Requirements

### Requirement: 控制台数据局部状态隔离
Dashboard 的当前余额 SHALL 使用独立查询和状态区域；六项指标、双趋势与最近请求 SHALL 使用单一 `/portal/api/dashboard/stats` 查询，并在成功响应内部按指标或集合的可用性分区呈现。余额失败不得清除成功的统计快照，统计失败不得清除余额；统计响应中的单项 `UNAVAILABLE` 或 `PARTIAL` 不得遮蔽同一响应中其他可用内容。请求日志页面 SHALL 继续使用独立分页查询。只有 `UNAUTHENTICATED` SHALL 触发统一会话失效流程。所有区域 MUST 使用共享设计系统，在加载、状态切换和重试时保持布局稳定，并在窄屏、键盘操作和 200% 缩放下保持可读和可操作。

#### Scenario: 余额区域单独失败
- **WHEN** Dashboard 统计成功而当前余额查询失败
- **THEN** 页面保留六项指标、趋势状态和最近请求，只在余额区域显示错误和重试

#### Scenario: 单个 Dashboard 区域失败
- **WHEN** 独立余额查询失败，或成功 stats 响应中的单个指标/集合标记为不可用或部分可用
- **THEN** 只有对应区域显示错误或业务状态，其他已成功区域保持可见且可操作

#### Scenario: 统一统计查询失败
- **WHEN** 当前余额成功而统一 Dashboard 统计查询失败
- **THEN** 页面保留余额与钱包入口，在统计区域显示一次错误状态和重试，不保留可能来自旧范围的局部统计数据

#### Scenario: 统计响应部分不可用
- **WHEN** 统一统计响应同时包含可用指标、不可用趋势和部分覆盖的最近请求
- **THEN** 每个区域按自己的可用性呈现，页面不把整个成功响应误判为加载失败或全空状态

#### Scenario: 会话统一失效
- **WHEN** 任一受保护余额、Dashboard 统计或请求日志接口返回 `UNAUTHENTICATED`
- **THEN** 应用清除认证范围缓存并进入登录流程，不继续显示余额、统计或日志快照

#### Scenario: 窄屏与放大查看 Dashboard
- **WHEN** 用户在窄屏或 200% 缩放下切换范围、查看指标、趋势状态和最近请求
- **THEN** 页面不产生整页横向溢出，快捷范围、状态说明和下钻链接保持可见、可聚焦且可通过触摸操作

#### Scenario: 窄屏查看请求日志
- **WHEN** 用户在窄屏访问请求日志并操作筛选与分页
- **THEN** 内容不产生整页横向溢出，主要筛选、状态和分页仍可通过键盘与触摸操作
