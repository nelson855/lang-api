## Why

请求日志需要清晰展示流式状态、总耗时、Token 和费用口径。2026-10-03 用户明确取消协议与首 Token 延迟展示，避免没有可信直接映射的数据占据页面或增加采集工作；本变更收缩为基础信息与费用闭环。

## What Changes

- 取消协议、首 Token 延迟（TTFT）两项页面展示及说明，不新增相关采集、映射、筛选或历史回填。
- 保留既有 API 可空 protocol/firstTokenLatencyMs 字段及旧响应兼容校验，后端继续返回 null，避免破坏已有接口。
- 保留流式状态、时间、Key、模型、输入/输出 Token、总耗时、结果、费用与请求标识；桌面和窄屏、中英文一致。
- 费用保留完整十进制金额、币种与原始 quota，提供键盘可访问说明，不重算正式汇总或供应商账单。
- 保留已有分页、筛选、URL 导航、Dashboard 下钻、隐私裁剪和会话失效清理。
- type=5 真日志、实际余额扣减与换算比例已于本地补验；原 6.1 明确记为需求取消，不记为验证通过。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `request-log-viewing`：明确取消两个辅助展示项、保留 API 兼容和基础信息/费用页面闭环。

## Impact

- 前端：RequestLogsPage、样式、中英文文案及页面/浏览器测试；API 校验兼容规则保留。
- 后端：保留现有 DTO、两个 null 字段、统一金额换算和已修复的真实时间字段及认证空邮箱兼容。
- 文档：更新当前范围、验收任务和阶段状态；保存旧实测记录，不把取消记为数据能力实现。
- 不增加配置、依赖、数据库或网关计时，无提交、归档或发布操作。
