## MODIFIED Requirements

### Requirement: 模型选择与文档联动
模型广场的列表与详情 SHALL 为每个目录模型提供“查看调用示例”入口，将原始模型 ID 作为 URL 查询参数导航到 `/docs`。文档 SHALL 仅在该 ID 精确存在于当前模型目录时采用它；参数缺失时 SHALL 选择当前目录中的确定性默认模型，若目录为空则不生成可调用示例。参数明确存在但为空、非法或模型已下线时 MUST 显示所选模型不可用和返回模型广场入口，不静默替换为其他模型，也不生成冒充所选模型的示例。URL 参数 MUST 经过编码和长度校验，且不得被插入 HTML 或命令结构的非数据位置。

#### Scenario: 从模型广场进入文档
- **WHEN** 用户选择模型 `model-x` 并从列表或详情打开调用示例
- **THEN** 页面导航到带编码模型参数的 `/docs`，文档加载目录后在所有示例中使用精确模型 ID `model-x`

#### Scenario: 查询参数指向未知模型
- **WHEN** `/docs` 收到不在当前模型目录中的模型参数
- **THEN** 页面不使用该值生成命令，明确显示所选模型不可用并提供返回模型广场入口，不默认切换其他模型

#### Scenario: 模型下线后刷新文档
- **WHEN** 先前指定的模型不再出现在当前公共模型目录
- **THEN** 文档停止生成该模型示例并展示所选模型不可用，不切换默认模型冒充所选模型

#### Scenario: 未指定模型
- **WHEN** 用户直接访问不含 model 参数的 `/docs`
- **THEN** 页面继续选择按模型 ID 排序后的首个可用目录模型，目录为空时显示无模型状态

#### Scenario: 显式模型参数非法
- **WHEN** model 参数为空或超过现有 ID 长度边界
- **THEN** 页面不使用它生成示例，也不回显可疑原文，显示安全参数提示与返回模型广场入口
