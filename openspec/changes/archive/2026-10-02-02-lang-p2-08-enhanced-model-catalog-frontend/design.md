## Context

动机见 [proposal.md](./proposal.md)。阶段依据为 `docs/11_第二阶段聚合能力开发与子需求拆分.md`：P2-02 已完成，P2-03～P2-07 已有受支持范围实现但仍受真实数据证据限制；下一项 P2-08 未开始。P2-07 归档任务为 31/31；没有活动 change。部分更早归档任务仍未勾选，归档本身不表示第二阶段完整验收。

当前 `ModelsPage.tsx` 只有列表、组件内部搜索/厂商状态和调用示例按钮；`providerOptions` 从列表派生选项。`api/models.ts` 仅有列表严格 schema，`useModels` 使用 30 秒 staleTime、关闭自动重试和窗口聚焦刷新。路由只有 `/models`，`metaForPath` 只支持静态精确路径。`DocsPage` 当前把未知指定模型静默替换为默认模型，需要为新详情到文档路径做局部修正。

后端三个公开接口已存在，详情路由接受规范 modelRef。`pricingVersion` 实现允许 null，不能假定每次响应均有可比较版本。增强字段当前均为 null，基础 TOKEN 价格已经有单模型实样核对；这些证据不证明额外计费或能力字段存在。接口基线见 `docs/16_LANG-P2-07-模型详情与供应商筛选接口说明.md`。

## Goals / Non-Goals

**Goals:**

- 建立不依赖先访问列表的公开详情路由，同时保留搜索/厂商上下文。
- 将接口解析、URL/模型引用转换、显示语义和跨响应一致性拆为可测试的小模块，页面负责组合状态和交互。
- 列表与详情使用相同价格规则、共享视觉和反馈，所有元数据只来自详情成功响应。
- 将当前全 null 基线与未来可信非空样本同时纳入测试；非空 fixture 只验证显示逻辑，不作为真实环境证据。

**Non-Goals:**

- 不调整目录后端、计费换算、缓存 TTL 或公共配置，不新增配置文件和数据库；dev/test/prod 继续使用现有 `.properties`。
- 不解除 P2-01/P2-07 数据来源阻塞，不增加模型运营、Playground、排序推荐、分页或虚拟列表。
- 不重做全站设计系统、文档协议与示例模板，不修改 AGENTS.md，也不引入独立审查或发布流程。

## Decisions

### 1. 使用独立详情页，沿用公开外壳

选择 `/models/:modelRef`，复用 `PublicLayout`、懒加载路由和页面标题机制。路由元信息对该模式作明确匹配，不能把所有 `/models/*` 都当作合法详情；详情不新增顶级导航项，公开导航仍指向模型广场。

详情分为“模型标识与操作 → 基础价格 → 限制/模态/能力 → 发布信息与标签 → 增强计费”。桌面可并排排布数据区，窄屏按相同阅读顺序堆叠。全 ID 采用等宽文本并允许换行，元数据用语义描述列表，价格用带标题的行式数据展示。使用现有冷调画布、白色工作面、细边框、钴蓝主操作与字体令牌，页面自然滚动。

备选详情抽屉需要处理深链接、刷新、焦点恢复和移动端覆盖层，复杂度更高；独立页更贴合现有路由和文档路径。列表不为了完整卡片去逐个拉取详情，避免 N+1 请求。

### 2. 分离列表、供应商和详情 API 契约

保留列表 schema 和 `MODELS_QUERY_KEY`，避免破坏 DocsPage。新增供应商与详情严格 schema，复用现有 `portalRequest`、请求包装、AbortSignal 和错误类型。详情 query key 含规范 modelRef；供应商使用独立固定 key；目录相关查询保持现有 30 秒 staleTime、5 分钟 gcTime、retry=false 和 refetchOnWindowFocus=false 基线。

限制、模态、能力、日期和增强价格均覆盖可空类型；增强金额沿接口合法十进制语义校验，不直接套用基础价格最多 6 位小数限制。公开接口不额外加认证依赖。任何非预期结构、ID 不一致或未知枚举按契约失败展示安全错误，错误数据不视为成功。

### 3. 集中模型引用与 URL 状态转换

`features/catalog` 内集中纯函数处理 UTF-8 base64url 无填充编解码、重编码规范性、ID 边界和安全路径。使用 TextEncoder/TextDecoder 的严格 UTF-8 转换，不对 Unicode 直接使用 btoa，也不使用 encodeURIComponent 冒充模型引用。对照后端斜杠、百分号、空格、中文、表情与非法输入用例。

列表 URL 使用 `q` 和 `provider`；重复参数读取首个，未使用参数不参与筛选；仅序列化支持的条件到受控列表/详情路径。搜索输入替换当前历史项，厂商明确选择形成历史项；输入法组合期间不触发导航，组合结束同步搜索。详情链接与返回链接只携带这两个参数，不设计可执行 `returnTo`。未知厂商显示独立的已选条件和清除入口，不伪造 Select 选项。

使用 local search 而不是后端查询，因为列表本身就是完整数组且现有契约要求本地过滤。清除操作立即更新结果并恢复焦点。

### 4. 供应商选项加载和一致性使用有界状态机

列表与供应商并行读取，各自保留 loading/error/success。列表失败停止目录展示；供应商失败保留列表、搜索和 URL 现存条件，禁用可选厂商并支持独立重试，成功空供应商数组不是错误。

两次成功响应版本均非 null 且不同，或版本未知且供应商名称/完整计数与列表对不上，进入冲突恢复：强制对相关 query 执行一轮成对网络重取；仍冲突则结束自动请求，提供手动重试。手动重试开启新一轮有界恢复，不由 render/useEffect 无限 invalidation。在已知版本相同的情况下也核对供应商结构，发现契约异常不启用错项。计数核对使用全部模型，不能使用搜索过滤结果。

版本缺失但结构核对成功可提供筛选，同时以简短状态提示“无法确认目录版本一致性”；不暴露上游或口径实现细节。两版本皆为空也属于未知。

从列表进入详情且缓存列表具有不同已知版本时，对列表与详情成对重取一轮；持续冲突仍可展示详情自身完整响应，提示暂时无法与目录对照，绝不拼接旧价格。直达详情只请求详情，缺少列表不构成错误，不为一致性强制加载列表。所有请求接收取消信号，query key 与当前路由绑定，不使用上一个模型作 placeholder。

备选强制三个接口始终同步获取会提高详情直达成本；备选完全忽略版本会误用跨刷新数据。本方案只校验确实要组合的数据。

### 5. 显示语义和价格格式化集中复用

基础金额以十进制字符串展示，采用字符串拆分处理本地化分组与小数点，不调用 Number/parseFloat/toFixed，避免损失精度。增强金额如以科学计数法返回，先用十进制字符串算法规范化；不引入新金额依赖。TOKEN 与 REQUEST 的字段/单位组合继续严格遵循现有契约；增强单位若不认识直接展示接口值，不推测计费维度。

`null`、`false`、`[]`、0 各自独立分支；未知显示暂无数据，false 表示不支持，空集合表示无，零显示零。四项能力始终可发现，其他区保留说明，避免当前全 null 基线呈现大片空白或消失布局。日期按日历日期本地化，不作为 UTC 时间点转换。描述/标签使用 React 文本渲染，不用 HTML 注入。`sortOrder` 解析但不改变当前目录顺序。

复制操作复用 Button、Toast 和剪贴板惯例，在列表/详情共用同一小组件或 hook；失败还需就地提供手动复制提示。导航使用 Link，不使用按钮模拟链接。每个区域最多一个主要操作，非主操作使用 outline/link。

### 6. 文档只在未指定模型时自动选默认值

区分 `params.has('model')` 与空/缺失值；显式 ID 必须精确匹配目录，否则显示所选模型不可用并停止生成示例。未指定时保留已有按 ID 排序选择首个可用模型的规则。修改仅限选择结果和提示，不调整现有 Base URL、协议、Key 占位符或模板规则。对应 delta 修改 `developer-documentation`，避免与现有主规格的静默默认回退冲突。

### 7. 验证按前端闭环分层

纯函数覆盖引用编解码、URL 恢复、未知厂商、版本状态、三值元数据、日期与精确价格；API 契约测试覆盖当前 null 样本及合成合法非空/非法样本。组件测试覆盖独立失败重试、404、ID 错配、取消竞态、复制和文档指定模型消失。

浏览器测试扩展现有 fixtures，仅为测试生成可信字段展示用的合成响应；覆盖中文/英文、桌面/375px、直接刷新详情、前进后退、搜索组合输入、Select 展开态、键盘路径与失败恢复。运行 frontend test/lint/build、相关 Playwright 和根 Maven verify；环境不可用就记录未验证，不将 fixture 当作真实字段证据。沿用现有开发服务验证，不执行 Compose 发布或付费模型调用。

## Risks / Trade-offs

- [当前增强字段全部未知] → 把基础信息和价格放在主要阅读位置，未知区以稳定布局显示暂无数据；不据此宣称完整增强来源验收。
- [pricingVersion 可空或未能标识每次快照变化] → 非空版本比较只是信号，供应商另做结构核对；详情自包含展示，仍不承诺跨请求原子一致。
- [供应商单独故障] → 搜索和已选条件继续工作，单独恢复选项，不擅自回退本地派生厂商。
- [旧 schema 严格解析与文档依赖列表] → 保留列表 DTO，新增独立 schema，跑目录与文档兼容回归。
- [测试里非空数据被误解为真实来源已验证] → 页面说明明确区分合成展示测试与冻结环境实测，阶段总纲保留阻塞。

本轮仅生成规划文件。后续实施需要新的 apply 请求，逐项验证后立即勾选 tasks。部署另需明确授权；若未来部署后需回退，回退前端制品即可，后端公共契约没有变更。代码完成后报告测试和 git status，保留未提交改动。
