## Why

第二阶段已推进到 LANG-P2-07：模型详情和供应商目录接口的 31 项任务已完成，但 `/models` 仍仅展示基础列表，从列表自行生成厂商选项，也没有模型详情或详情深链接。下一部分 LANG-P2-08 将现有可信接口接入公开模型广场，让用户完成筛选、查看详情、复制模型 ID 和进入接入说明的闭环，同时明确展示缺失数据。

## What Changes

- 通过 `/portal/api/model-providers` 提供厂商筛选项和目录计数，搜索继续在完整列表上本地执行；使用 URL 保存搜索和单选厂商状态。
- 增加公开独立详情路由 `/models/:modelRef`，使用 UTF-8 网址安全 Base64 无填充模型引用，支持刷新、直达、返回原筛选结果与浏览器历史导航。
- 接入 `/portal/api/models/{modelId}`，展示基础信息、上下文、最大输出、输入/输出模态、四项能力、发布时间、描述、标签及增强价格；未知值显示“暂无数据”，不推断、不伪造。
- 列表和详情复用精度安全的价格展示，明确 USD/每百万 Token/每次请求单位，并保留真实零值；增强价格按响应提供的币种和单位展示。
- 列表与详情均提供复制原始模型 ID、进入 `/docs?model=...` 的入口；复制失败保留可选中的完整 ID。
- 增加独立加载、空态、筛选无结果、非法引用、404、接口失败、版本冲突和重试行为；支持中英文、键盘和窄屏。
- 已知版本不一致时有界重取；版本为空时说明无法确认跨请求版本一致性，不将两个 null 视为版本一致的证据。
- 仅实施当前基线可支持的前端闭环，不解除 P2-01/P2-07 的增强来源阻塞，不新增付费实测要求。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `model-catalog`：厂商筛选改用目录接口；增加 URL 可恢复状态、公开详情深链接、元数据与价格诚实展示、复制与文档入口、跨请求一致性和异步恢复要求。
- `developer-documentation`：显式指定模型不存在或参数非法时展示所选模型不可用，不静默替换；未指定模型时保留默认选择。

## Impact

- 前端：`frontend/src/api/models.ts`、`useModels.ts`、`features/catalog/*`、`ModelsPage.tsx`、`DocsPage.tsx` 的指定模型选择、新增模型详情页、公开路由与路由元信息、中英文资源，以及单元/组件/浏览器测试。
- 复用已有 React Router、TanStack Query、Zod、SearchField、Select、Button、反馈与 Toast 组件，沿用 `DESIGN.md` 和现有 CSS 令牌，不引入组件库或新依赖。
- 后端三个公开目录接口及其 DTO、缓存、计费和配置保持现有契约；不访问 New API 原始接口，不增加写操作。
- 实施后新增 LANG-P2-08 页面说明，更新阶段总纲，分开记录“当前可支持前端范围完成”与“增强来源仍受阻”。本次提案不修改业务代码、主规格或阶段状态，不启动独立审查、提交或发布。
