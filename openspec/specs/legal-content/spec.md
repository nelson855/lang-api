# legal-content Specification

## Purpose

为公开站点提供来源明确、经过服务端安全处理且可判断是否正式发布的用户协议与隐私政策，并在第一阶段不伪造正文、不保存版本或用户同意记录。

## Requirements

### Requirement: 匿名法律内容接口
系统 SHALL 提供匿名 `GET /portal/api/legal/terms` 与 `GET /portal/api/legal/privacy`。成功响应的 `data` MUST 只包含 `type`、`title`、`contentHtml` 和 `locale`；正文分别来源于冻结版 New API 的用户协议与隐私政策配置，不得使用 Portal 内置占位正文替代。

#### Scenario: 读取已发布用户协议
- **WHEN** 上游用户协议存在有效正文
- **THEN** 用户协议接口通过统一成功包装返回净化后的正文、配置语言和 Lang API 自有标题

#### Scenario: 法律正文未发布
- **WHEN** 对应上游正文为空、只有空白、超过上限或净化后没有有效正文
- **THEN** 接口返回统一 `NOT_FOUND`/404，不返回占位条款、上游消息或默认品牌

#### Scenario: 使用错误方法
- **WHEN** 客户端使用 GET 以外的方法访问任一法律内容接口
- **THEN** 系统返回统一 JSON `METHOD_NOT_ALLOWED`/405

### Requirement: 法律正文服务端安全转换
系统 SHALL 按 `.properties` 声明的 `MARKDOWN` 或 `HTML` 源格式解析正文，并在服务端使用固定白名单生成 `contentHtml`。白名单 MUST 移除脚本、样式、事件属性、表单、嵌入内容、远程图片和危险 URL 协议；只允许法律文档所需的标题、段落、列表、引用、代码、表格、分隔线和安全链接。前端 MUST 仅在专用法律正文组件中渲染该 HTML，不得再次插入未净化内容。

#### Scenario: 正文包含主动内容
- **WHEN** 上游正文包含 script、iframe、表单、事件属性或 `javascript:` 链接
- **THEN** 危险节点和属性被移除，浏览器不会执行或请求这些内容

#### Scenario: Markdown 包含 HTML
- **WHEN** 源格式为 `MARKDOWN` 且正文混入原始 HTML
- **THEN** 转换结果仍经过同一 HTML 白名单，不因 Markdown 解析绕过净化

#### Scenario: 正文包含外部安全链接
- **WHEN** 正文包含合法 HTTPS 外部链接
- **THEN** 链接可以保留，但新窗口链接具有 `noopener noreferrer`，且页面不会将上游站点当作 Lang API 品牌入口

### Requirement: 正文大小与短期缓存受控
法律正文 SHALL 在解析前执行字节上限，在净化后执行输出上限，并按法律类型缓存最近一次成功结果，缓存时长来自有界的 `.properties` 配置。缓存过期后的上游失败或无效正文 MUST 按未发布处理，不得无限期提供过期正文；失败、空正文和原始正文不得进入共享缓存。

#### Scenario: 有效正文命中缓存
- **WHEN** 同一法律类型在成功结果缓存有效期内被重复请求
- **THEN** 系统直接返回同一净化结果，不重复请求 New API

#### Scenario: 缓存过期后正文被清空
- **WHEN** 成功缓存已过期且上游正文变为空白
- **THEN** 后续请求返回未发布状态，不继续提供无期限旧正文

#### Scenario: 正文超过大小限制
- **WHEN** 原始正文或净化输出超过配置上限
- **THEN** 系统安全失败且不在响应、异常或日志中输出整段正文

### Requirement: 公开法律页面与注册前入口
前端 SHALL 提供 `/terms` 与 `/privacy` 公开页面，展示加载、正文、未发布和失败状态；正文标题结构、链接和焦点行为 MUST 可通过键盘和屏幕阅读器使用。登录前的注册页面及公共页脚 MUST 始终提供两个法律页面入口，即使正文尚未发布也不得隐藏路径。

#### Scenario: 匿名阅读法律正文
- **WHEN** 用户从注册页或页脚进入已发布的法律页面
- **THEN** 页面显示与运行时启用语言一致的标题和净化正文，无需登录

#### Scenario: 正文尚未发布
- **WHEN** 法律接口返回未发布状态
- **THEN** 页面明确说明内容尚未就绪并提供返回或支持联系入口，不显示模拟正文

#### Scenario: 窄屏阅读长文
- **WHEN** 用户在窄屏阅读包含长链接、代码或表格的正文
- **THEN** 页面保持可读，局部内容可安全换行或滚动且不造成整页横向溢出

### Requirement: 第一阶段不建立同意版本系统
第一阶段 SHALL 把法律正文视为部署时公开内容，不保存正文快照、版本号、发布时间、历史记录或用户同意记录，也不得宣称已经取得可审计的协议同意。开发者条款在获得正式正文前 MUST NOT 以占位页面发布。

#### Scenario: 用户完成注册
- **WHEN** 用户在法律正文可用且注册开放时创建账号
- **THEN** 系统不写入法律版本或同意记录，也不在响应中伪造版本标识

#### Scenario: 上游正文发生变化
- **WHEN** 运维更新 New API 中的法律正文且缓存失效
- **THEN** 页面展示新正文，但系统不生成虚构版本历史
